# VideoForYou 录屏工坊

桌面录屏工具，用来录自己做的桌面软件演示（musicForYou / bokeForYou 这类 Electron 工具）。
画面 + 系统声音 + 麦克风一起录，滤镜、贴图、鼠标高亮都是**实时烧进画面**的，录完即成品，不用再转码。

## 跑起来

```bash
npm install
npm run dev        # 开发模式（热更新）
npm run build      # 构建
npm run icon       # 重新生成 build/icon.ico（改图标设计时用）
npm run dist       # 打包安装版 / 便携版 / 绿色版到 release/
```

## 功能

- **画面**：整块屏幕或单个窗口，多显示器可选；输出分辨率（原始 / 4K / 2K / 1080P / 720P）、帧率（24/30/60）、码率（4~24M）
- **声音**：系统声音回环（Windows / macOS 13+）+ 麦克风，两路独立音量与电平表，录音时不会外放
- **特效**：10 种实时滤镜（清晰/暖阳/胶片/黑白/高饱和…）、暗角、噪点、水印
- **贴图**：本地图片贴图、文字标注、Emoji、摄像头画中画（圆形/圆角/方形、可镜像加白边）；可拖动、缩放、旋转，支持浮动/呼吸/抖动/旋转动画
- **鼠标**：录屏本身拍不到指针，这里补一个圆环/圆点/光晕高亮，还能让画面跟随鼠标放大（讲解细节用）
- **构图**：适应留边 / 铺满裁切 / 拉伸填满，背景可选纯黑、石板、渐变或模糊画面，可调留白、圆角、投影、镜像
- **录制体验**：倒计时、暂停/继续；录制时主窗口留在桌面上照常可点，同时弹出置顶悬浮控制条
- **快捷键**：`Ctrl+Shift+P` 暂停/继续，`Ctrl+Shift+S` 停止
- **作品库**：录完自动收进库里（默认 `视频\VideoForYou`），可回放、定位、删除

## 几个设计取舍

- **录制时为什么不挪窗口**：给主窗口开了内容保护（Windows 的 `WDA_EXCLUDEFROMCAPTURE`），
  任何抓屏都拍不到它，所以窗口可以原地留着、按钮照常点。实测把窗口整片涂成品红后录像，
  解码出来 12000 个采样点里 0 个标记色。
  「输出」里的「录制时把主窗口挪出画面」是兜底开关：万一某些机器内容保护失效，打开它会把窗口移出被录区域。
- **为什么不能最小化窗口**：窗口一隐藏，`canvas.captureStream()` 就不再出帧（实测录出来 0 字节），
  所以宁可挪位置，也绝不最小化。
- **为什么停止后不弹保存对话框**：对话框挂在窗口上，窗口位置一旦不对就看不见，
  界面会卡在「正在保存…」，用户会以为所有按钮都失灵。现在停止后直接收进作品库，一秒内跳结果页，
  要另存或定位文件在结果页点一下就行。
- **为什么边录边写临时文件**：整段视频不放内存，`MediaRecorder` 的分片按秒写进临时目录，收尾时再搬到作品库，
  长录像也不会吃爆内存。
- **MP4 优先**：Chromium 新内核支持 `MediaRecorder` 直接出 H.264 + AAC 的 MP4，抖音/剪映都能直接用；
  内核不支持时自动降级 WebM 并在界面上提示。

- **悬浮条为什么按需创建、用完即销毁**：留着一个隐藏窗口会让「关掉主窗口」不触发 `window-all-closed`，
  进程赖在后台占着单实例锁，用户再点图标只是静默退出（v0.1.0 的 bug，v0.1.1 修）。

## 已知限制

- Linux 不支持系统声音回环，只能录麦克风
- 鼠标高亮/跟随放大是合成出来的光标，不是系统原生指针；录制单个窗口时不会显示光标高亮
- 录制自己的界面时，被录的那块屏上其他窗口的遮挡关系会被忠实记录，讲解前建议先清一下桌面

## 结构

```
src/main/      主进程：画面源枚举、displayMedia 接管、分片落盘、作品库、clip:// 协议
src/preload/   contextBridge 暴露给渲染层的 API
src/renderer/  界面 + 合成器（lib/compositor.ts）+ 录制管线（hooks/useRecorder.ts）
src/shared/    两端共用类型
scripts/       图标生成（纯 Node 写 PNG/ICO，无第三方依赖）
```
